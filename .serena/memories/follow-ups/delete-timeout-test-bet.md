# Follow-up — `delete.test.ts`'s `WORKER_TIMEOUT` test bets on a duration

**Status: CLOSED 2026-11-14** — `test/delete-timeout-deterministic` merged; seen 2026-11-13. Not re-run on macOS since.

Part of `mem:follow-ups`.

- **Seen:** macOS 26 matrix on `test/close-immediate-safari` (run 43462109531, cancelled afterwards), cell `firefox · OPFSWriteAheadVFS/sync`: `delete.test.ts` › "rejects with WORKER_TIMEOUT once its timeout is spent" — "promise resolved "undefined" instead of rejecting".
- **Cause (diagnosed 2026-11-14, by reading the code and the run's log):** a race the platform does not order, not a library defect. `runDelete` (`src/delete.ts`) ALWAYS spawns a worker (the earlier note here, "deleted without a worker", was wrong: since `fix/delete-without-vfs` a VFS with a folder — `OPFSWriteAheadVFS`, `OPFSAdaptiveVFS`, `OPFSCoopSyncVFS`, `OPFSAnyContextVFS` — is deleted by the worker *without loading the engine*, `deleteFolderDatabase`). The deadline is armed right after the spawn with the remaining budget, which for `timeout: 1` is ≤ 0 once the two lock acquisitions have run, i.e. a `setTimeout(0)`. The test bet that this timer task runs before the worker's `deleted` message; nothing orders a page timer against a worker message, and a fast engine-less worker can win. The log reads `resolved "undefined"`: the deletion succeeded, which is correct — the timeout is when the worker is *presumed unable to answer*, and it answered. Other VFS load the engine first, so the bet almost always held there, still a bet (`mem:follow-ups/time-based-tests`).
- **Fix (test only):** the test swaps `Worker` for one that starts and never answers (a Blob running `self.onmessage = () => {}`, as `lifecycle.test.ts`'s `Silent`), so `WORKER_TIMEOUT` is the only way out on every pair; it restores `Worker` in a `finally` before the cleanup deletes the database with a real worker, and asserts the one worker spawned was terminated. Green on all 16 cells (`--full`); falsified by a mutant dropping `worker.terminate()` from `settle` (3 Chrome cells red on the `terminated` assertion).
- **Also seen in the same campaign, unrelated:** macOS 27 `isolated-safari · MemoryVFS/sync`, `early-exit.test.ts` › "a break out of chunk() cuts the step it left running" — not exercised ("the count was not computing before the break"); the pair green.
