| 2026-09-22 | `fix/transaction-statement-queue` | **Two statements created in the same tick inside a `transaction()` no longer lose the transaction.** `await Promise.all([tx.read(…), tx.read(…)])` — baseline usage of a concurrency library — met the pool's reuse guard and failed under a name that pointed at a generator the consumer never opened; the user's call put it in rc.5 as a real bug rather than rc.6 as a comfort. Statements now queue in ISSUE order, `commit`/`rollback` and each `bulkWrite` batch included. **A worse defect surfaced on the way and made no noise**: a `bulkWrite` batch posted a microtask after `flush()`, so a read issued AFTER it ran first and returned stale rows — a count of 2 where the table held 4. Three implementation traps, each recorded in the code: the uncontended path must post SYNCHRONOUSLY or a statement whose own signal aborts in that microtask never reaches the worker (caught by the pre-commit hook, spec R7); a generator's slot releases on the pool's new `free()` — resolved where `deferredChunk` is cleared — because `quiesce()` waits for a transport `finally` a parked consumer never reaches; and **a queue place left early is handed on, not cancelled**, found only by testing the abort axis with every ordering test green. `GENERATOR_ABANDONED` became `WORKER_BUSY` with its message rewritten, free of charge because rc.5 is unpublished — a classification the user corrected twice. The contract change owed to consumers: a `chunk()`/`stream()` nobody is pulling still holds the connection, so what follows it WAITS where it used to fail, and the library warns rather than deciding, since abandoned and slow are indistinguishable. **The coverage behind all of it**: `Promise.all` appeared in none of the eight transaction test files; there are now 14 transaction tests and 9 client-level ones, every client one green on arrival because a lease is held until the worker is idle — that asymmetry is the finding. One red in the third verification pass was mine: a test waiting seven seconds loaded the cell where `tx-savepoint`'s T4 measures interrupt latency (`mem:lessons`). 15 commits; bounded design in chat, no spec. Merge `4b57e86`. |
