OMG tier slows down an Asyncify-instrumented WebAssembly function

SQLite compiled to WebAssembly by Emscripten (wa-sqlite, loaded from jsDelivr), in three builds of the same C code: sync (no Asyncify), async (Asyncify) and jspi (JSPI). Each build runs in its own worker and repeats the same query 400 times: a full scan of a 200,000-row in-memory table (one sqlite3_step() call, no I/O, nothing ever suspends). The page prints the mean time of every 25 queries.

Expected: each build stays flat. Observed: async runs at ~14 ms per query, then, after a few seconds of work, jumps to ~180 ms and stays there; sync and jspi stay flat.
